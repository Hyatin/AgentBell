# AgentBell v0.6.0-beta.1 release notes source

> Preparation source only. No tag or GitHub Release has been created.

## Highlights

- Complete English and Simplified Chinese UI for the Windows Tray, local pairing page, Android app, notifications, Setup, and uninstaller.
- Independent **Follow system**, **English**, and **简体中文** settings on Windows and Android.
- Exact `zh-CN` system matching; unsupported locales fall back to English.
- Language settings persist across restarts without clearing pairing, devices, events, or connection configuration.
- Resource-key, format-placeholder, unsupported-locale, persistence, notification, installer-message, and hardcoded-string tests.

## Compatibility

Protocol version 1, HTTP/API routes, WebSocket messages, Hook arguments, `hooks.json`, pairing tokens, and configuration formats remain compatible with 0.5. Existing configuration gains only the optional `language` value and defaults safely to `system`.

## Security and installation

AgentBell still uses authenticated HTTP/WS on a trusted private LAN; traffic is not end-to-end encrypted. Never share pairing URLs or QR codes. If Windows binaries do not have a trusted Authenticode signature, this remains an unsigned Beta and Microsoft Defender SmartScreen may warn. Public Android assets must be release APKs signed with the long-term release key; debug APKs are not release assets.

Setup offers English and Simplified Chinese. The uninstaller reuses the Setup language and preserves non-AgentBell Hooks. The installer does not replace the existing Codex `notify` command.
