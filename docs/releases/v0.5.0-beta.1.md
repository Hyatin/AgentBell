# AgentBell v0.5.0-beta.1

AgentBell sends an Android system notification when a Codex turn completes on a Windows computer. This is the first public beta pre-release.

## Included

- User-level Codex Stop Hook with legacy M0 notify-input compatibility.
- Windows 10/11 x64 Tray, loopback HTTP ingestion, event sanitization, persistence and deduplication.
- Authenticated RFC1918 LAN WebSocket with resume/reconnect.
- Native Android app with QR pairing, foreground connection, notification history, and heads-up notifications.
- Per-user Setup, safe Hook merge/repair/uninstall, startup option, diagnostics, checksums, audit and release tooling.

## Requirements and installation

Use Windows 10/11 x64 and Android 8.0 (API 26) or later on the same trusted private LAN. Download Setup, the release APK, and `SHA256SUMS.txt`; verify SHA-256 before installation. Run Setup, then review and trust the exact stable `AgentBell.Hook.exe --codex-stop-hook` path when Codex asks. Existing Codex `notify` is not changed. Install the APK, scan the Tray QR, grant notifications, and adjust vendor battery/autostart settings if needed.

If a debug-signed Android build is already installed, it usually cannot be upgraded by the release-signed APK. Uninstalling it removes phone-side pairing data. Every later public release must use the same long-term release key.

## Security and privacy

There is no cloud service, account, telemetry, or advertising SDK. Local diagnostics are sanitized. Pairing uses a random token, Windows DPAPI, and Android Keystore. HTTP/WS traffic is **not end-to-end encrypted** and must only be used on a trusted LAN. Never share pairing QR/URLs, private config, event history, complete Hook files, prompts, replies, or raw logs.

The Windows beta may be published without a trusted Authenticode certificate. Microsoft Defender SmartScreen can warn because a new unsigned executable has no publisher reputation. Verify the GitHub source and SHA-256; checksums and provenance do not replace Authenticode. The Android public asset must be a long-term release-key-signed release APK, never a debug APK.

## Known limitations

- Codex, Windows x64, and Android only; no cloud relay or public-network support.
- A notification indicates a turn ended, not that the overall task is complete.
- No real progress percentage or remote Codex control.
- Android vendor background restrictions may interrupt connectivity.
- Artifact attestation availability depends on GitHub plan and repository settings.

## Reporting bugs

Use the repository template with synthetic data. Do not upload secrets, QR codes, raw logs, complete diagnostic ZIPs, prompts, or responses. Follow `SECURITY.md` for vulnerabilities.
